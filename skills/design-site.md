# design-site
The full interface pass, in the order that avoids rework: system first so
every later decision has a token to use, layout second, accessibility woven in
rather than bolted on, critique last when there is something real to judge.

Work through the parts below in order. Do not skip the critique — the point of
doing it last is that it is the only pass that can see the finished thing.
